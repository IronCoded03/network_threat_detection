# Data

The dataset files are **not committed**. This folder is git-ignored apart from this README.

1. Go to the UNSW-NB15 page: https://research.unsw.edu.au/projects/unsw-nb15-dataset
2. Follow its download link and open the CSV files folder.
3. Download these files into this folder:
   - `UNSW_NB15_training-set.csv` (175,341 records)
   - `UNSW_NB15_testing-set.csv` (82,332 records)
   - `UNSW-NB15_features.csv` (feature descriptions)
